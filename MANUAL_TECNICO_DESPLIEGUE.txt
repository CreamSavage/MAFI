2.1 CREACIÓN DE BASE DE DATOS Y USUARIO

CREATE DATABASE mafi CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

2.2 IMPORTACIÓN DE DATOS
--------------------------------------------------------------------------------

2.3 NORMALIZACIÓN DE NOMBRES DE TABLAS
--------------------------------------------------------------------------------
PROBLEMA: Linux MySQL es case-sensitive; las tablas se crearon con mayúsculas.
SOLUCIÓN: Renombrar todas las tablas a minúsculas.

Comando SQL completo:
    mysql -u MAFI -p'SistemaMAFI2025' mafi << 'EOF'
    RENAME TABLE Usuarios TO usuarios;
    RENAME TABLE Inscripciones TO inscripciones;
    RENAME TABLE Clases TO clases;
    RENAME TABLE Anuncios TO anuncios;
    RENAME TABLE Comentarios TO comentarios;
    RENAME TABLE Accesos TO accesos;
    RENAME TABLE Notificaciones TO notificaciones;
    SHOW TABLES;
    EOF


2.4 VERIFICACIÓN DE TABLAS
--------------------------------------------------------------------------------
Ver todas las tablas:
    mysql -u MAFI -p'SistemaMAFI2025' -e "USE mafi; SHOW TABLES;"

Contar registros en usuarios:
    mysql -u MAFI -p'SistemaMAFI2025' -e "SELECT COUNT(*) FROM mafi.usuarios;"

4. NORMALIZACIÓN DE CÓDIGO SQL EN ARCHIVOS PHP
================================================================================

4.1 PROBLEMA IDENTIFICADO
--------------------------------------------------------------------------------
Las consultas SQL usaban nombres de tablas con mayúsculas (FROM Usuarios, 
JOIN Inscripciones, etc.) que no funcionan en Linux MySQL donde los nombres
de tablas son case-sensitive.


4.2 CORRECCIÓN MASIVA EN SERVIDOR

8. PROBLEMAS COMUNES Y SOLUCIONES
================================================================================

8.1 ERROR: "Unknown database 'MAFI'"
--------------------------------------------------------------------------------
CAUSA:     Nombre de base de datos en mayúsculas en conexion.php
SOLUCIÓN:  Editar /var/www/html/SistemaMAFI/conexion.php
           Cambiar: $db_nombre = 'MAFI'
           Por:     $db_nombre = 'mafi'


8.2 ERROR: "Table 'mafi.Usuarios' doesn't exist"
--------------------------------------------------------------------------------
CAUSA:     Tablas con mayúsculas en sistema Linux MySQL (case-sensitive)
SOLUCIÓN:  Opción 1 - Renombrar tablas en MySQL:
               RENAME TABLE Usuarios TO usuarios;
           Opción 2 - Corregir consultas SQL en archivos PHP
               (ver sección 4.2)


8.3 ERROR: Access denied for user 'MAFI'@'localhost' (1045)
--------------------------------------------------------------------------------
CAUSA:     Credenciales incorrectas o usuario sin permisos
SOLUCIÓN:  Verificar contraseña en conexion.php
           Verificar permisos en MySQL:
               SHOW GRANTS FOR 'MAFI'@'localhost';
           Recrear usuario si es necesario:
               DROP USER 'MAFI'@'localhost';
               CREATE USER 'MAFI'@'localhost' IDENTIFIED BY 'SistemaMAFI2025';
               GRANT ALL PRIVILEGES ON mafi.* TO 'MAFI'@'localhost';
               FLUSH PRIVILEGES;


8.4 ERROR: 403 Forbidden
--------------------------------------------------------------------------------
CAUSA:     Permisos incorrectos en archivos/directorios
SOLUCIÓN:  Restablecer permisos:
               sudo chown -R www-data:www-data /var/www/html/SistemaMAFI
               sudo find /var/www/html/SistemaMAFI -type d -exec chmod 755 {} \;
               sudo find /var/www/html/SistemaMAFI -type f -exec chmod 644 {} \;


8.5 ERROR: Base de datos se conecta pero login falla
--------------------------------------------------------------------------------
CAUSA:     Mismatch entre nombres de tablas en consultas SQL
SOLUCIÓN:  Ejecutar corrección masiva (ver sección 4.2)
           Verificar con:
               grep -i "FROM.*usuario" /var/www/html/SistemaMAFI/Login/procesar_inicio.php


8.6 ERROR: Cannot modify header information - headers already sent
--------------------------------------------------------------------------------
CAUSA:     Espacios en blanco o salida antes de header()
SOLUCIÓN:  Verificar que archivos PHP no tengan BOM
           Verificar que no haya salida antes de header()
           Usar ob_start() al inicio del script si es necesario

10. COMANDOS DE MANTENIMIENTO

10.1 BACKUP DE BASE DE DATOS
--------------------------------------------------------------------------------
Crear backup completo:
    mysqldump -u MAFI -p'SistemaMAFI2025' mafi > backup_mafi_$(date +%Y%m%d_%H%M%S).sql

Crear backup de estructura solamente:
    mysqldump -u MAFI -p'SistemaMAFI2025' --no-data mafi > estructura_mafi.sql

Crear backup de datos solamente:
    mysqldump -u MAFI -p'SistemaMAFI2025' --no-create-info mafi > datos_mafi.sql


10.2 RESTAURAR BASE DE DATOS
--------------------------------------------------------------------------------
    mysql -u MAFI -p'SistemaMAFI2025' mafi < backup_mafi.sql


10.3 VER LOGS DE APACHE
--------------------------------------------------------------------------------

    sudo tail -f /var/log/apache2/error.log

Ver accesos en tiempo real:
    sudo tail -f /var/log/apache2/access.log

    sudo tail -n 100 /var/log/apache2/error.log

--------------------------------------------------------------------------------

13. NOTAS ADICIONALES
================================================================================

13.1 DIFERENCIAS ENTRE WINDOWS Y LINUX
--------------------------------------------------------------------------------
- Linux es case-sensitive en nombres de archivos y tablas MySQL
- Windows no distingue mayúsculas/minúsculas
- Por eso las tablas deben estar en minúsculas en Linux


13.2 SEGURIDAD
--------------------------------------------------------------------------------
- Las contraseñas están hasheadas con password_hash() de PHP
- Se usa SessionToken para validar sesiones únicas
- Se implementa verificación de email con tokens
- Hay sistema de recuperación de contraseña con tokens temporales


13.3 ENVÍO DE CORREOS
--------------------------------------------------------------------------------
El sistema usa PHPMailer para envío de correos
Configuración en archivos de procesamiento de registro, verificación, etc.
Requiere configuración SMTP válida para producción
